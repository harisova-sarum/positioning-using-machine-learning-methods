# Позиционирование в помещении по параметрам радиосигнала методами машинного обучения

Исследовательский проект по определению координат точки приёма внутри помещения на основе данных лучевого трассирования (ray tracing) радиосигнала от передатчика: сравнение точности нейронной сети, линейной регрессии и метода k ближайших соседей.

## Задача

Каждая точка помещения характеризуется набором параметров до 15 лучей сигнала, приходящих от передатчика: мощность, фаза, время прихода, углы вылета (AoD phi/theta) и углы прихода (AoA phi/theta). Задача — по этим параметрам восстановить координаты (x, y) точки, то есть решить задачу позиционирования как задачу регрессии.

## Данные

- `Начальные данные/` — исходные CSV-файлы с результатами трассирования лучей для разных сценариев помещения (пустое помещение / помещение с препятствиями, 1 или 3 передатчика)
- Каждая строка данных — точка помещения с координатами (x, y, z) и параметрами до 15 лучей сигнала
- Точки, попадающие в стены/недоступные зоны, отфильтровываются перед обучением моделей

## Методы машинного обучения

- `Linear_regression.py` — позиционирование методом линейной регрессии (`sklearn.linear_model.LinearRegression`) по мощности лучей
- `Nearest_neighbors.py` — позиционирование методом k ближайших соседей (`KNeighborsClassifier`, k=3)
- `1_Tx_Empty_Room.py`, `1_Tx_Observed_Room.py` и аналогичные — позиционирование полносвязной нейронной сетью (Keras/TensorFlow, 2 скрытых слоя по 25 нейронов)

Во всех трёх подходах точность оценивается методом leave-one-out (поочерёдно каждая точка используется как тестовая, остальные — как обучающая выборка), метрики — среднеквадратичная (MSE) и средняя абсолютная (MAE) ошибка отдельно по осям X и Y.

## Сравнение сценариев

- `1_Tx_Empty_Room.py` / `1_Tx_Observed_Room.py` — сравнение точности позиционирования в пустом помещении и при наличии препятствий (объекта наблюдения), один передатчик
- `1_Tx_Empty_Room_With_Averaging.py`, `1_Tx_Observed_Room_With_Averaging.py` — та же задача с усреднением измерений сигнала для снижения шума
- `1_Tx_Empty_Room_Points_Droping.py` — вариант с отбраковкой части измерительных точек
- `3_Tx*.py` — те же эксперименты при использовании трёх передатчиков вместо одного, включая раздельный анализ ошибки по осям X и Y (`3_Tx_2_point_on_X.py`, `3_Tx_2_point_on_Y.py`) и сравнение способов усреднения результата, включая последовательное усреднение (`3_Tx_Result_Averaging.py`)
- `3_Tx_room_size_reserch.py` — исследование зависимости точности позиционирования от размера помещения
- `3_stand_alone_radio_cards.py` — эксперимент с автономными радиомодулями (отдельно от основного сценария передатчиков)

## Подбор гиперпараметров модели

- `Power_1_Tx_Empty_Room_Number_Of_neurons_check.py` — исследование зависимости точности нейросетевой модели (MSE/MAE по X и Y) от количества нейронов в скрытом слое (перебор от 1 до 201 с шагом 25), используется только мощность лучей как признак

## Стек

Python (pandas, NumPy, scikit-learn, TensorFlow/Keras, matplotlib, seaborn), MATLAB (частично, для отдельных вспомогательных расчётов)

## Результаты

**Сравнение методов.** Нейронная сеть (2 скрытых слоя по 75 нейронов) показала точность выше, чем метод k ближайших соседей и линейная регрессия:

| Метод | x_mae, м | y_mae, м | x_mse | y_mse |
|---|---|---|---|---|
| k ближайших соседей | 6.6 | 1.2 | 66.5 | 3.1 |
| Линейная регрессия | 4.0 | 3.3 | 21.1 | 17.6 |
| Нейронная сеть | **3.9** | **2.7** | **20.6** | **12.5** |

**Выбор признаков.** Лучшую точность даёт комбинация мощности сигнала и углов вылета луча (AoD): x_mae = 1.6 м, y_mae = 1.4 м, геометрическая ошибка d = 4.8 м — против d = 16.3 м при использовании только мощности сигнала. Добавление фазы луча, напротив, ухудшает точность и делает предсказание невозможным для точек у несущих стен.

**Число лучей.** Снижение числа используемых лучей с 15 до 10 почти не ухудшает точность по X и заметно улучшает точность по Y; дальнейшее уменьшение числа лучей увеличивает ошибку.

**Итоговый результат.** При обучении на данных помещения с препятствиями базовая модель даёт x_mae = 2.2 м, y_mae = 3.9 м. После добавления в датасет признака «номер подкомнаты» точность выросла до **x_mae = 1.8 м, y_mae = 1.4 м**.
